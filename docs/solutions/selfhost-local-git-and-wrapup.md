# Local git and tool-round wrap-up

A leftover `remote.<name>.pushurl` used to stop every jail git command, including `status` and `commit`. Local-only mode skips remote transport keys (`remote.<name>.pushurl` and `remote.<name>.push`) only for commands that do not contact a remote, and only when the bot has no GitHub grant or the workspace has no remote. `push`, `fetch`, `pull`, `clone`, `ls-remote`, `remote`, and `submodule` still refuse those keys. Keys that change local command behavior stay refused for every command. The host check in `RepoConfigDenied` still refuses `remote.*.pushurl` for the bare mirror. Do not add `remote.*.promisor` or `partialclonefilter` to the wrapper: an existing test treats those strings as an opened allowlist.

Tool-round wrap-up reserves the last round when the effective budget is 4 to 7, and the last two rounds when it is 8 or more. Budgets under 4 are unchanged, because the note would consume the run. The note is injected once per run. The run still ends with `error_code=tool_rounds` and the existing limit sentence, and stores `stop_reason=tool_rounds_exhausted`. Continue copies the held transcript, including the note, and gets a fresh budget.
