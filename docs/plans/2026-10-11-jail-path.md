# Jail PATH

The shell already bind-mounts `/usr` and `/bin` read-only. `go` is installed at `/usr/local/go/bin/go` and works by full path. PATH is only `/usr/bin:/bin`, so the name is missing.

## Decisions

- PATH is the standard system directories plus toolchain directories that already sit on that mount: `/usr/local/go/bin`, `/usr/lib/go/bin`, `/usr/local/sbin`, `/usr/local/bin`, `/usr/sbin`, `/usr/bin`, `/sbin`, `/bin`. A directory that does not exist is left out.
- Nothing new is mounted. Home, `/snap`, and nvm stay off PATH. The `build` grant is still only the extra read-only binds.
- The model prompt says those installed tools are on PATH.

## Tests

- The jailed `PATH` matches that list and does not contain a home directory or `/snap`.
- When `/usr/local/go/bin/go` exists, `command -v go` prints that path.
