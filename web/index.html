Approval rules

Rules match an exact command or a pattern. A prompt never offers a pattern.

How a request is decided

  1. Any deny (exact or pattern, any scope).
  2. Several parts ask, unless every part is granted for this task.
  3. Critical asks. No rule, pattern or task grant approves a critical item.
  4. Narrowest scope: task > bot > global. Within one scope, exact beats pattern, then ask beats allow.
  5. No match asks.
